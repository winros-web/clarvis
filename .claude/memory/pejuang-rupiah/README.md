# Agen Pejuang Rupiah

Folder kerja untuk agen `pejuang-rupiah` (definisinya ada di
`.claude/agents/pejuang-rupiah.md`). Semua catatan keuangan dan ide
penghasilan disimpan di sini agar bertahan antar sesi.

| File | Isi |
|---|---|
| `target.md` | Tujuan keuangan dan progresnya |
| `catatan.md` | Buku kas: pemasukan, pengeluaran, utang/piutang |
| `ide.md` | Ide penghasilan tambahan dan statusnya |

**Jangan simpan nomor rekening, PIN, password, atau data kartu di sini.**
Folder ini ikut ter-commit ke GitHub.

## Format `catatan.md`

```
## 2026-09

| Tanggal | Jenis | Jumlah | Keterangan |
|---|---|---|---|
| 2026-09-08 | masuk | Rp5.000.000 | Proyek website klien A |
| 2026-09-07 | keluar | Rp150.000 | Langganan tools |
```

Jenis: `masuk`, `keluar`, `utang` (saya berutang), `piutang` (orang berutang
ke saya).
