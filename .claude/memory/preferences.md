# Preferensi Kerja

## Komunikasi

- Bahasa Indonesia, nada santai-profesional. Tidak perlu formal berlebihan.
- Langsung ke inti. Tanpa basa-basi pembuka atau pujian ("Pertanyaan bagus!").
- Ringkas dulu, detail menyusul kalau saya minta.
- Kalau ada trade-off, beri **satu rekomendasi**, jangan daftar semua opsi.

## Cara kerja

- Kerjakan sampai tuntas. Jangan berhenti di bagian yang mudah saja.
- Kalau ada bagian yang tidak bisa dikerjakan, selesaikan sisanya dan sebutkan
  eksplisit apa yang dilewati dan kenapa.
- Verifikasi sebelum lapor selesai (jalankan test/lint, bukan asumsi).
- Untuk tindakan yang sulit dibatalkan (hapus file, force push, kirim ke pihak
  luar): konfirmasi dulu.

## Kode

- TypeScript strict. Ikuti gaya kode yang sudah ada di file sekitarnya.
- Jangan tambah komentar berlebihan — ikuti kepadatan komentar file tersebut.
- Jangan tambah dependency baru tanpa alasan kuat dan tanpa memberi tahu saya.

## Git

- Semua pekerjaan di branch `claude/johan-okdianoko-bxunzd` kecuali saya bilang lain.
- Commit message bahasa Inggris, format: `type: deskripsi singkat`
  (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`).
- Jangan buat pull request kecuali saya minta eksplisit.
- Jangan push ke `main`.
