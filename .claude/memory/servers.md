# Daftar Server

Inventaris server untuk subagen `teknisi-server`. **Jangan simpan rahasia di
sini** (password, private key, token) — cukup alias dan kegunaannya. Detail
koneksi (HostName, User, IdentityFile) ada di `~/.ssh/config` di mesin lokal.

| Alias SSH | Kegunaan | Service penting | Catatan |
|---|---|---|---|
| _(contoh) `prod`_ | _VPS API clarvis_ | _nginx, docker_ | _jangan restart di jam kerja_ |
