# Preferensi Kerja

## Komunikasi

- Bahasa Indonesia, santai-profesional. Tanpa basa-basi pembuka.
- Ringkas dulu, detail menyusul kalau diminta.
- Kalau ada trade-off, beri **satu rekomendasi**.
- Angka selalu dalam Rupiah dengan pemisah ribuan: `Rp1.250.000`.

## Cara kerja

- Baca memori dulu, baru jawab. Tulis kembali setiap ada data atau keputusan
  baru.
- Kerjakan sampai tuntas. Kalau ada yang tidak bisa, sebutkan eksplisit.
- Untuk tindakan yang sulit dibatalkan: konfirmasi dulu.

## Keuangan

- Periode budget: bulanan, mulai tanggal 1.
- Cara menilai pengeluaran: bandingkan dengan sisa budget bulan ini dan
  dampaknya ke target di `target.md`.
- _(tambahkan aturan pribadi lain di sini, mis. "maksimal cicilan 30% dari
  pemasukan")_

## Git

- Commit message bahasa Inggris, format `type: deskripsi singkat`.
- Jangan buat pull request kecuali diminta.
